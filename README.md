# КонсольГрад

**[Открыть сайт — consolegrad.online](https://consolegrad.online/)**

Основной адрес проекта — собственный домен **consolegrad.online**.

Коммерческий лендинг команды, занимавшейся проектированием и запуском игровых комнат под ключ: от подбора оборудования и планировки до монтажа PlayStation-зон и подготовки площадки к работе.

![Реализованная игровая комната](assets/cases/spa-lounge/case-01-1600.webp)

## Задача

Собрать понятную продающую витрину, которая показывает не абстрактную услугу, а полный цикл работ и реальные результаты: игровые станции, гоночные симуляторы, помещение, оборудование и внутреннее программное обеспечение.

## Что реализовано

- адаптивный лендинг без тяжёлого frontend-фреймворка;
- каталог услуг и этапов реализации проекта;
- кейс игровой комнаты с фотографиями и видео;
- отдельная страница внутреннего продукта PS Lounge;
- форма первичного брифа для клиента;
- SEO-метаданные, Open Graph, sitemap и robots.txt;
- юридические страницы;
- Docker-образ на Nginx для публикации;
- автоматические smoke-проверки структуры сайта.

## Контекст проекта

«КонсольГрад» занимался реализацией игровых пространств под ключ. Практическая работа включала установку и подключение PlayStation-станций, подготовку оборудования и запуск площадок. Лендинг фиксирует этот опыт и показывает потенциальному клиенту готовый результат.

PS Lounge представлен на сайте как отдельный внутренний инструмент для управления сессиями игровой площадки. Исходный код приложения опубликован в самостоятельном репозитории и не смешан с кодом лендинга.

## Структура

```text
index.html          основной лендинг
pslounge.html       страница продукта PS Lounge
script.js           интерактивность и анимации
styles.css          визуальная система и адаптивность
assets/             фото, видео, логотипы и UI-материалы
tests/              проверки структуры и ссылок
Dockerfile          контейнер сайта на Nginx
nginx.conf          конфигурация веб-сервера
```

## Локальный запуск

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:4173/index.html`.

## Проверка

```powershell
powershell -ExecutionPolicy Bypass -File tests/site-smoke.ps1
node --check script.js
```

Проверяется наличие ключевых страниц и файлов, целостность локальных ссылок, уникальность HTML `id`, SEO-адреса и базовая корректность JavaScript.
